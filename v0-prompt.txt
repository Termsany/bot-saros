Raqm — Trading Terminal Dashboard (Global v1)

IDENTITY (متفرد):
- Colors: Obsidian #070B12 bg, Emerald #00D395 for LONG/profit, Crimson #FF3B5C for SHORT/loss, Amber #FFB800 for pending, Steel #8A9AB0 muted, Border #1E2A3A
- Typography: JetBrains Mono for numbers, Inter for Arabic/English, font-black for KPIs
- Texture: subtle grid noise, glow on profit card, glass blur header
- No generic crypto purples — terminal / Bloomberg vibe

LAYOUT (Dashboard lays immediately):
- Header glass: S logo + Raqm wordmark + FUTURES x5 pill + LiveTicker + Backtest link
- KPI strip (5 cards): Total PnL (emeral/crimson border pulse), WinRate, PF, Open, Closed
- Two panels: 
  LEFT (right visually 360px): StrategyPicker 5x3 cards (icon + WR/PF color) + Selected count + tier warning + command hint + open trades + closed trades
  CENTER/MAIN: TradingView Lightweight Charts — candlesticks 200, auto-refresh 30s from Binance REST (api.binance.com -> fapi fallback), entry/exit markers (arrowUp #00D395 belowBar, arrowDown #FF3B5C aboveBar, circle P/L), empty fallback "loading..."
- Footer: 15 strategies — ICT hero note

NOTES:
- Chart must NOT be blank: direct Binance fetch (api.binance.com/api/v3/klines), parse [openTime, open, high, low, close], time as seconds, sort ascending
- Trades from /api/trades on Render backend (https://bot-saros-backend.onrender.com)
- RTL for Arabic labels but numbers LTR

Build with Next.js 14 + lightweight-charts + @supabase/supabase-js + stripe. All data live.
